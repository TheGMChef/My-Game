- Platform: mobile (Android and/or iOS, to be decided)
- Stage: concept

## Getting started

1. Open this repo in Claude Code.
2. Run `/start` to set the project up and choose how much design documentation you want before coding.
3. Run `/brainstorm` to develop the game concept, then `/setup-engine` to lock in the engine.

Project settings live in `project.yaml`. Design docs go in `design/` and `docs/`, and source code goes in `src/`.
